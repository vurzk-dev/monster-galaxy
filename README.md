# Nuestra Misión 🎯:

**Monster Galaxy Rewritten** nace con el objetivo de devolver a los fans el clásico **Monster Galaxy**. El proyecto busca preservar la experiencia original del juego Flash, manteniendo viva la esencia del juego y, al mismo tiempo, continuar su desarrollo mediante nuevas mejoras y contenido.
